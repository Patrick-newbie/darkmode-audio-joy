# Audio Player Delight

Erstelle ein ansprechendes GUI im Darkmode mit HTML, CSS und nur Javascript welche folgende Aufgaben löst: Dem Benutzer stehen drei MP3 Dateien zum abspielen bereit. Jede Datei hat folgende Buttons zur Auswahl:

- einen Play-Button
- einen "Zurück zum Anfang"
- 10 Sekunden vorwärts-Button
- 10 Sekunden zurück Button
